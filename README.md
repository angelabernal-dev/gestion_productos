# Sistema de gestión de productos

Aplicación web desarrollada con PHP y MySQL para administrar productos. Proyecto académico realizado en SENATI.

## Descripción

El sistema implementa las operaciones **CRUD** para la administración de productos y aplica **programación orientada a objetos (POO)** en su desarrollo.

## Tecnologías

- PHP
- MySQL
- HTML y CSS
- Programación orientada a objetos (POO)
- Servidor local [XAMPP]

## Funcionalidades

- Registro de productos
- Listado y consulta de productos
- Edición de productos
- Eliminación de productos

## Cómo ejecutarlo

1. Clona el repositorio dentro de la carpeta de XAMPP:
   ```
   git clone https://github.com/bernalestradaangelavaleria-sys/[nombre-del-repo].git
   ```
2. Inicia Apache y MySQL desde XAMPP.
3. Crea la base de datos e importa el script desde phpMyAdmin.
4. Configura la conexión en el archivo.
5. Abre en el navegador: `http://localhost/[nombre-del-repo]`
